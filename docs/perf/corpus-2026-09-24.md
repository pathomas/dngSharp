## Notes on this run

- **GPU clock throttling.** `nvidia-smi` sampled during the run shows the
  Quadro P520 holding 1531 MHz SM for the first ~15 s, then dropping to
  **139 MHz** (throttle reason `0x20`, SW thermal slowdown, at only 56–60 °C —
  a laptop firmware policy). GPU render time per 24 MP file steps from
  0.16 s → 0.63 s accordingly and stays there. Decode and JPEG encode are CPU
  and unaffected. The GPU at 139 MHz is still ~3× faster than 8 CPU threads.
- An earlier pass the same evening stayed unthrottled for all 52 files
  (0.18 s render per file, render stage **12.8×**, end-to-end **2.94×**); see
  `corpus-2026-09-24-run1-unthrottled.md`. That pass predates the Stage 2
  early-release change, so its device peak is 893 MB vs 618 MB here and the
  two 50 MP panoramas OOM'd there but fit here (1728 MB).
- `IMG_2906-HDR-Pano.dng` (≈70 MP) still exceeds 2 GB on the resident path.
  A banded render is the fix.
- Input DNGs: 40 Lightroom HDR merges (Float16 LinearRaw, 3-plane, ~24 MP),
  6 "Enhanced-NR" (UInt16 Bayer 6288×4056 + JXL enhanced IFD), 3 panoramas,
  and 6 others. GPU support for Float16 Stage 1 was added for this run.
- JPEG encode (SkiaSharp, serial) is now **43 %** of GPU-path time; Stage 1
  decode 18 %. Those two are the next levers.
